# 에이전트 지침 관리

적용 대상: `AGENTS.md`, `CLAUDE.md`, `docs/agents/`, `.agents/skills/`, `.claude/`.

- 공통 규칙은 AGENTS.md와 상세 문서, 재사용 절차는 로컬 스킬에서 관리한다. Claude 문서는 공통 원본을 참조한다.
- 프로젝트의 실제 제약과 반복해서 확인된 실패를 기록한다. 일반적인 프로그래밍 설명, 중복 예제, 모델 이름별 수동 절차는 추가하지 않는다.
- 규칙을 바꿀 때 목적과 적용 범위를 확인하고 연결된 문서·스킬을 함께 정리한다. 사용자가 규칙 개선을 요청했다면 기존 강제 절차도 근거를 갖고 수정할 수 있다.
- 작은 문서 수정은 링크·일관성·차이 검사로 확인한다. 동작·권한·완료 기준을 크게 바꾸는 지침 개편은 별도 에이전트에게 전체 변경과 현실적인 작업 사례를 읽기 전용으로 검토시킨다. 실질적인 결함을 고치고 확인하며 형식적인 승인 문구를 얻기 위한 반복은 하지 않는다.
- `.claude/settings.json`과 훅은 Claude 전용이다. 지침을 썼다는 이유만으로 자동 실행·권한·차단 장치가 설치됐다고 간주하지 않는다. 보호 경로 편집은 실행 환경의 정상 도구를 사용한다.

설계 참고: [OpenAI Codex 작업 지침](https://learn.chatgpt.com/guides/best-practices). 모델 선택·권한 설정은 실행 환경에서 관리하고 저장소 지침에는 작업에 필요한 제약과 검증 기준을 둔다.
